## Provenance

The cut was generated by `nomadguard` through the API path, not hand-assembled:

```
job 20261106-003651-6e0d54   FINALIZED   $0.50
  video   MiniMax-H3-Lite, 768P, 3 shots x 4 s + provider overshoot = 13.4 s
  images  image-01 keyframes, hero frame as reference_image for later shots
  voice   speech-2.8-turbo ("English_Persuasive_Man")
  QA      technical pass; creative realism 7, consistency 8, brief 7, hook 6, ad quality 7 (mean 7.0)
```

The provider returns 768x1344, which is 1.75:1 rather than 9:16. It was conformed
once, without regeneration, so the deliverable is exactly the platform ratio:

```bash
ffmpeg -i nomadguard-ad-768p.mp4 \
  -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,setsar=1" \
  -c:v libx264 -preset slow -crf 20 -pix_fmt yuv420p \
  -c:a aac -b:a 96k -movflags +faststart nomadguard-ad-final.mp4
```

A 1.6% horizontal crop, no letterboxing, no speed change. `qa.json`'s technical
block was then re-measured on this file (`1080x1920`, `9:16`, 13.4 s, decodable,
audio present); the creative scores are unchanged because the frames are the same.
